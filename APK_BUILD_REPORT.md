## Option A: Install via USB + ADB

### Step 1: Enable USB Debugging on Phone
1. Open **Settings** → **About phone**
2. Tap **Build number** 7 times to enable Developer Options
3. Go back to **Settings** → **System** → **Developer options**
4. Enable **USB debugging**
5. Plug phone into PC via USB cable
6. Tap "Allow" on phone when it prompts about debugging

### Step 2: Install via ADB
```bash
# Navigate to the APK location
cd C:\Users\a5149169\OneDrive\ -\ Renesas\ Electronics\ Corporation\Desktop\workspace_25\simpletanpura

# Install the APK
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

### Step 3: Verify Installation
```bash
# Check if app is installed
adb shell pm list packages | grep com.myriyaz.tanpura

# Expected output:
# package:com.myriyaz.tanpura
```

### Step 4: Launch App
```bash
# Open app on phone
adb shell am start -n com.myriyaz.tanpura/com.myriyaz.tanpura.MainActivity
```

**Or**: Just look for "My Riyaz" icon on your phone home screen and tap it.

### Troubleshooting Option A
**If `adb: command not found`**:
- Install Android SDK Platform Tools
- Add to PATH: `C:\Users\a5149169\AppData\Local\Android\sdk\platform-tools`
- Restart terminal

**If `device not found`**:
- Ensure USB cable is plugged in
- Enable USB debugging on phone
- Run: `adb devices` to verify phone shows up
- May need to install phone-specific USB drivers

**If `INSTALL_FAILED_*` error**:
- Uninstall old version first: `adb uninstall com.myriyaz.tanpura`
- Clear app data: `adb shell pm clear com.myriyaz.tanpura`
- Try install again

## Option B: Direct File Transfer + On-Device Installation

### Step 1: Enable Installation from Unknown Sources
1. Open **Settings** → **Apps** (or Applications)
2. Tap **Special app access** (or Advanced)
3. Enable **Install unknown apps** for:
   - Chrome, Firefox, or your preferred file manager
   - Gmail, WhatsApp, etc. (if using to transfer file)

### Step 2: Transfer APK to Phone

#### Method 1: USB File Transfer
1. Plug phone into PC via USB cable
2. On phone: Swipe down notification, tap "File transfer" or "Transfer files"
3. On PC: Open File Explorer, find phone under "This PC"
4. Copy `app-debug.apk` to phone's `Downloads` folder
5. Disconnect phone

#### Method 2: Cloud Storage
1. Upload APK to Google Drive, OneDrive, or Dropbox
2. On phone: Open the cloud storage app
3. Download `app-debug.apk` to Downloads folder

#### Method 3: Email or Messaging
1. Email the APK to yourself or use WhatsApp/Telegram
2. Open attachment on phone
3. File saves to Downloads

### Step 3: Install App on Device
1. Open **Files** app (or **Downloads** folder)
2. Find `app-debug.apk`
3. Tap the file
4. Tap **Install** (or **Allow** if prompted)
5. Wait for installation to complete
6. Tap **Open** to launch app

### Step 4: Launch App
- Tap "Open" in install dialog, OR
- Find "My Riyaz" icon on home screen and tap it

### Troubleshooting Option B
**If "Install unknown apps" permission not found**:
- Settings varies by phone manufacturer
- Try: Settings → Security → Allow installation from unknown sources

**If APK won't install due to "Unsafe file"**:
- Chrome or your browser may block it
- Download via file manager instead
- Or use a different method (cloud storage, email)

**If "App not installed" error**:
- Uninstall previous version first
- Ensure phone has at least 200MB free storage
- Restart phone and try again
